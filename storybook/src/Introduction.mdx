## 🧭 사용 원칙

1. **Figma 원본 우선** — 문서·기존 코드와 어긋나면 Figma 가 진실
2. **아이콘은 직접 그리지 않음** — Figma vector 좌표 그대로 이식
3. **토큰 사용** — hex 하드코딩 금지 (`--color-brand-primary` 등 CSS variable)
4. **Pretendard 통일** — Regular / Bold 두 굵기만

## 🔗 Code Connect

Figma 컴포넌트 인스턴스와 코드가 자동 연결돼 있어요.
Dev Mode 에서 컴포넌트 선택 시 아래와 같은 스니펫이 자동 반환됩니다:

```tsx
<Button size="large" color="Brand">확인</Button>
<Input state="active" placeholder="입력하세요" />
<Tooltip variant="line" placement="bottom-left">Tooltip Text</Tooltip>
```

새 컴포넌트 매핑 추가 시:

```bash
cd storybook
npm run figma:publish
```
