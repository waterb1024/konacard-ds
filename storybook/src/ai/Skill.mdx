# Skill

KONACARD 통합 스킬. 기획서로 화면을 만드는 일과 디자인 시스템을 관리하는 일을 나눠 담당 에이전트에게 맡겨요.

<div className={styles.draft}>
  <strong>초안</strong> — 스킬을 고치면서 이 페이지와 설치 파일도 같이 바꿔요.
</div>

konacard-ds 스킬은 AI 에이전트가 KONACARD 화면과 디자인 시스템 작업을 도울 때 불러오는 안내서예요.

문서에 이미 있는 내용은 스킬에 옮겨 적지 않아요. 색·글꼴 같은 기본 값, 컴포넌트 명세, 화면 규칙은 디자인 시스템 문서와 Figma 원본이 기준이고, 복사본은 원본보다 먼저 낡기 때문이에요. 스킬은 요청을 세 가지로 나눠 알맞은 담당에게 넘겨요.

- **화면 만들기** — 기획서(Confluence · PRD · Figma · 이미지)를 읽고, 어떤 종류의 화면인지 판단해 계획을 세운 뒤, Figma 에 디자인 시스템 컴포넌트로 화면을 조립하고 규칙에 어긋난 곳을 점검해요
- **기존 화면 바꾸기** — 이미 있는 Figma 화면을 복제해, 복제본의 요소를 KONACARD 컴포넌트 · 텍스트 스타일 · 색 변수로 바꿔요 (원본은 그대로 둬요)
- **디자인 시스템 관리** — Figma 원본에서 값을 뽑아 Storybook 컴포넌트를 만들고, Figma 에서 코드가 보이도록 연결하고, 문서와 Figma 가 다른 곳을 바로잡아요

화면을 조립하기 전에는 반드시 사용자 승인을 받아요. 계획을 먼저 보여 주고, "조립해줘" 같은 확인이 있어야 Figma 를 고쳐요.

## Installation

사내망(VPN)에 연결된 상태에서 아래 명령을 터미널에 붙여 넣으세요. 이 사이트에서 `konacard-ds` 스킬과 에이전트를 받아 설치해요.

- Claude Code 를 새로 열면 바로 쓸 수 있어요. **업데이트**는 같은 명령을 다시 실행하면 되고, 바뀌는 기존 파일은 `.claude/konacard-backup/` 에 남겨요.
- 받기 전에 내용을 보고 싶으면 <a href="/skill/install.sh" target="_blank">install.sh</a> · <a href="/skill/manifest.txt" target="_blank">파일 목록</a> 을 열어 보세요.
- Figma 파일 키는 스킬 파일에 넣지 않았어요 (`${FIGMA_DS_FILE_KEY}` 로 표시). 팀 관리자에게 받아 쓰세요.
