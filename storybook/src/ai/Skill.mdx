# Skill

KONACARD 통합 스킬. 기획서로 화면을 조립하는 흐름과 디자인 시스템을 유지관리하는 흐름을 나눠 에이전트에게 맡깁니다.

<div className={styles.draft}>
  <strong>작성 중</strong> — 스킬을 정리하는 중이라 설치 방법과 SKILL.md 원문은 확정되면 채웁니다.
</div>

konacard-design 스킬은 AI 에이전트가 KONACARD 화면과 디자인 시스템 작업을 도울 때 로드하는 가이드입니다.

문서에 이미 있는 것은 스킬에 옮겨 적지 않습니다. 토큰 값·컴포넌트 명세·화면 규칙은 디자인 시스템 문서와 Figma 원본이 기준이고, 복사본은 원본보다 먼저 낡습니다. 스킬은 요청을 두 흐름으로 나눠 알맞은 에이전트에게 넘깁니다.

- **화면 생산** — 기획서(Confluence · PRD · Figma · 이미지)를 읽고, 화면 성격을 판단해 조립 계획을 세운 뒤, Figma 에 DS 컴포넌트로 화면을 조립하고 안티패턴을 검토
- **DS 유지관리** — Figma 원본에서 값을 추출해 Storybook 컴포넌트를 만들고, Code Connect 를 반영하고, 문서와 Figma 의 차이를 바로잡음
