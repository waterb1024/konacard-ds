# 화면 패턴 — 약관 · 공지 화면

> `konacard-ds-rule.md` 에서 옮겨 온 화면별 표준 패턴. 공통 규칙(화면 성격 분류 · 색 · 글자 · 간격 · 톤앤매너 · 하지 말 것)은 `konacard-ds-rule.md`, 다른 패턴은 같은 폴더의 다른 파일에 있음. 문서 안 § 참조는 이름으로 찾으면 됨.

## 표준 패턴 — 다층 그룹 약관 동의 화면

여러 약관(필수 + 선택)을 한 번에 동의받는 화면의 표준 구조 (회원가입, 이용약관 진입 등).

- **위계는 상황별로 2단 or 3단:**
  - **3단** (필수 + 선택 약관 혼재) — 최상위 마스터(전체 동의) → 그룹 헤더(필수 모두/선택 모두) → 개별 항목
  - **2단 축약** (필수 약관만) — 최상위 마스터(`[필수]` 마커 접두어) → 개별 항목. 그룹 헤더 생략, 마스터가 그룹 성격 겸함 (예: 오픈뱅킹 약관 동의)
- **최상위 마스터** — 원형 채움 체크, Bold 라벨. 필요 시 부가 설명 병기 (예: "본인은 만 14세 이상입니다.").
- **그룹 헤더** (3단일 때) — 원형 채움 체크, Bold 라벨.
- **개별 항목** — 라인 √ 체크 + 라벨 + 우측 `>` 상세 진입.
- 하단 CTA — 조건 충족(필수 동의 완료 시) 활성.

### `[필수]` vs `(필수)` 마커 표기 위치 규칙

| 마커 | 위치 | 스타일 | 언제 |
|---|---|---|---|
| **`[필수]` / `[선택]` 대괄호** | 라벨 **앞 접두어** | Bold 검정 (라벨과 동일 색·굵기) | **그룹 마스터·묶음 헤더**의 성격 강조 마커 (예: "**[필수] 이용약관 전체동의**") |
| **`(필수)` / `(선택)` 괄호** | 라벨 **옆(뒤)** | 회색 작게 | **개별 항목의 부가 정보** 속성 표기 (예: "카메라 **(선택)**", "저장소 **(선택)**") |

- 대괄호 = 그룹 마커·강조 / 괄호 = 개별 속성·부가 정보. **혼용 금지.**
- **리스트 아이템 카테고리 마커로도 확장 사용** — 공지사항의 `[안내]` / `[공지]`처럼 리스트에서 아이템의 카테고리를 라벨 앞 접두어로 표시 가능 (Bold 검정, 색 구분 없이 모두 통일).

## 표준 패턴 — 시스템 공지·긴급 알림 화면

앱 점검·서버 오류 등 시스템 상황을 알리는 최상위 오버레이 화면.

- **액션바 없음** (상태바만) — 시스템 오버레이 성격
- **중앙 배치**:
  1. **원형 보라 알림 아이콘 (`ic_alram_brand_56`)** — 완료 체크와 유사한 원형 배경, 안에 종/알림 라인 아이콘
  2. **헤드라인 "확인해 주세요."** — Bold 검정, 중앙 정렬, 강조 없음
  3. **회색 배경 안내 카드** (`background/secondary`) 안에 상황 안내 텍스트 (검정 Regular, 중앙 정렬)
- **하단 CTA** — 상황에 맞는 극단적 액션 라벨 (예: "앱 종료")

## 표준 패턴 — 약관 상세 페이지

여러 진입점(회원가입 약관 동의, 소득공제 신청, 카드 안내사항 등)에서 열리는 **약관 상세 페이지의 표준 구조**.

- **헤드라인**: `{약관 타이틀 명}` — 짧고 전체 보라 강조
- **셀렉트 드롭다운**: 약관 버전 날짜 선택 (`YYYY.MM.DD ▽`) — `select/select box` 컴포넌트(구 input/select), 헤드라인 아래 배치
- **약관 내용**: 스크롤 컨테이너 안에 조항별로 배치
  - **조항 타이틀** — Bold 검정, 본문보다 살짝 큰 크기 (예: "제1조 (목적)")
  - **조항 본문** — Regular 검정 텍스트
  - **다층 depth 지원** — 1 depth / 2 depth / 3 depth 각각 크기·들여쓰기로 위계 표현
- **↑ 상단 이동 플로팅 버튼** (선택) — `Button/Fixed_UP` 52x52 원형 아웃라인. 우측 하단 고정(하단 CTA 위 20px), 스크롤 시 나타남. 긴 스크롤 콘텐츠에 사용.
- **하단 CTA는 진입 목적에 따라 다름:**

| 진입 목적 | 액션바 왼쪽 | 하단 CTA |
|---|---|---|
| **새 동의 받기** (회원가입 약관, 소득공제 신청 등의 진입) | 우상단 `×` (모달성) | **"동의하기"** (Primary, 스크롤 완료 or 조건 충족 시 활성) |
| **이미 동의된 약관 조회** (카드 안내사항의 이용약관 등) | 좌상단 `<` (스택형) | **CTA 없음** or **"확인"** (닫기 목적) |
