# 화면 패턴 — 카드 · 홈 · 이용내역

> `konacard-ds-rule.md` 에서 옮겨 온 화면별 표준 패턴. 공통 규칙(화면 성격 분류 · 색 · 글자 · 간격 · 톤앤매너 · 하지 말 것)은 `konacard-ds-rule.md`, 다른 패턴은 같은 폴더의 다른 파일에 있음. 문서 안 § 참조는 이름으로 찾으면 됨.

## 표준 패턴 — 한도 조회·상향 화면 (MYCARD_LIMIT)

카드 한도 조회 → 상향 트리거 → 본인 인증 → 상향 확정으로 이어지는 4단 플로우.

### 한도 조회 화면 (LIMIT) 구조

액션바(`<` + 타이틀) → 섹션 반복(섹션 헤더 → 한도 카드 → 유의사항 `●`). 섹션 사이 두꺼운 divider (10px bar).

### 섹션 헤더 3요소

한도 조회·상향 화면의 각 섹션 상단 헤더 표준 구조:

| 위치 | 요소 |
|---|---|
| 좌 | 섹션 헤딩 (`heading/2-bold` 검정, 예: "해외결제") |
| 헤딩 옆 (선택) | **상태 pill** (예: "한도 상향 전", "한도 상향 완료") |
| 우 | **안내 링크** — 텍스트 + `>` chevron (예: "결제 안내 >", "출금 정보 >") |

- 안내 링크 스타일: 회색 텍스트 + 회색 chevron *(추측)*, 관련 안내 화면으로 진입
- 상태 pill 유무: 상태 정보가 필요한 섹션만 노출

### 상태 pill 스타일 진행 규칙

같은 성격 상태 pill이 진행 단계에 따라 스타일 변화:

| 단계 | 스타일 | 예 |
|---|---|---|
| **진행 전** (아직 안 함) | 진한 보라 아웃라인 pill (`border/brand`) + `font/brand` 텍스트 | "한도 상향 전" |
| **진행 완료** (완료 됨) | 연보라 채움 pill (`background/tertiary`) + `font/brand` 텍스트 | "한도 상향 완료" |

- **§ "Pill 배지 (3색 통합 규칙)"과의 매칭**: 아웃라인 = 조건부 미충족·대기 / 옅은 보라 채움 = 완료·활성 (두 규칙 연결)
- 상태 pill이 시간·프로세스에 따라 스타일 변경되는 케이스 표준

### 한도 카드 구조

각 한도 유형(일·월·연) 반복 아이템:

| 요소 | 스타일 |
|---|---|
| **진행바 (Progress Bar)** | 회색 트랙 + brand 채움 (사용률 시각화), § "진행바 (Progress Bar) 통일 규칙" 매칭 |
| **사용량 라벨 pill** | 진행바 상단 우측에 얹힌 pill — `button/primary` 채움 + 흰 텍스트, 예: "420만원 이용" |
| **라벨·값 라인** | 좌: "현재 결제 가능 금액" (검정) / "일 한도" (회색), 우: 사용가능액 (bold 검정) / 한도 (회색) |
| 각 유형 사이 | dotted divider — `black 6%`(`#0F000000`), solid line과 동일 색·`dasharray 2 2`만 다름 |

- **진행바 위 사용량 라벨 pill** — 진행바 트랙 위에 사용액을 pill로 얹는 형태. 진행바 색이 진행률에 따라 다른 위치에 있어도 사용액 정확히 표시.
- 카드 배경 = 회색(`background/secondary`) 또는 흰 카드 안 다이내믹 콘텐츠

### 한도 상향 화면 (LIMIT_INCREASE)

- **액션바**: `<` + "ATM 출금 한도 상향" 타이틀
- **헤드라인 부분 강조**: 액션 대상만 brand — 예: "**상향할 출금한도를**(brand) 확인해주세요."
- **한도 상향 비교 카드** (§ 아래)
- **`ⓘ 확인해주세요.` 유의사항 리스트** (§ 안내 도입어 규칙 매칭)
- **하단 CTA "한도 상향하기"** (Large Brand)

### 한도 상향 비교 카드

before → after 상태를 시각적으로 비교하는 카드.

| 위치 | 요소 |
|---|---|
| 좌 | "1회 한도" 라벨 (bold 검정) + "상향 전 / 50만원" (회색 라벨·값) |
| 중앙 | `→` 화살표 (회색) — 변화 방향 |
| 우 | "상향 후 / 100만원" (bold 검정) — after 강조 |

- 회색 배경 카드 (`background/secondary`)
- 여러 한도 유형(1회·1일·월) 아이템 반복
- 아이템 사이 얇은 divider
- **§ "선택형 리스트 카드"·"진입형 리스트"와 다른 카드 유형** — before/after 비교 성격

### 섹션 카드 안 CTA 버튼

전체 화면 하단 CTA와 별개, 섹션별 액션 트리거 (Section-level CTA).

- 위치: 섹션 카드 안 or 바로 아래
- 크기: Medium (Large 아님)
- 스타일: `background/tertiary` 연보라 + `font/brand` 텍스트 (Secondary Brand 계열) *(추측)*
- 예: 해외 ATM출금 섹션 "출금 한도 상향"
- 섹션 상태에 따라 조건부 노출

### 인증번호 입력 화면 (LIMIT_CERTIFICATION) 4상태

카카오톡·SMS 인증번호 입력 표준 화면 4단계.

| 상태 | 필드 | 카운트다운 | 하단 CTA | 키패드 |
|---|---|---|---|---|
| **입력전** | 아웃라인 회색 + placeholder | 없음 | 없음 | 활성 |
| **입력중** | 아웃라인 brand + 검정 텍스트 | red "M:SS" | 없음 | 활성 |
| **입력완료** | 아웃라인 회색(off-focus) + 검정 텍스트 | red "M:SS" | **Brand 채움 "인증하기"** 노출 | 사라짐 |
| **에러** | 아웃라인 red + red 텍스트 + 아래 `ⓘ` red 문구 | red "M:SS" | **회색 채움 disabled** | 활성 |

- **헤드라인 부분 강조**: "출금 한도 상향을 위해 / **인증번호를 입력**(brand)해주세요."
- 부가 안내에 `{010-1234-5678}` 중괄호 플레이스홀더 (§ "표기 규칙")
- **§ input Active/Complete/Error 규칙 매칭**

### 인증번호 필드 + 재요청 Small 버튼 인라인 배치

필드 우측에 **"재요청" Small 버튼**을 별도 배치 (필드 안 어드먼트 아님).

- 필드: 고정 퍼센트가 아니라 **필드=Fill(가변, 남은 공간 전부 차지) / 재요청 버튼=Hug(컨텐츠 너비에 고정)** auto-layout 규칙. 우측 gap 8
- 재요청 Small 버튼: brand_line 아웃라인 pill (§ "Small 버튼")

### 인증번호 필드 안 카운트다운 (Right adornment)

필드 안 우측 잔여 시간 "M:SS", `font/accent-red` red (§ `accent/primary` 6용도 ③ 긴급 알림).

### 하단 CTA disabled 2 variant 구분

| 유형 | 스타일 | 상황 |
|---|---|---|
| **회색 채움** | `background/quaternary` + `font/tertiary` | 필수 조건 미충족 (필드 미입력·에러) — 사용자 액션으로 활성화 |
| **Opacity 40%** | 원본 색(brand) opacity 40% | 일시적 대기 (로딩·처리 중) — 시스템 대기 |

시그널 차이: 회색 채움 = "채우세요" / Opacity = "잠시만".

### 안티패턴 (하지 말 것 — 한도 화면)

- ❌ 진행바 위 사용량 라벨 pill을 진행바 아래로 이동 — 반드시 트랙 상단
- ❌ before/after 비교 카드에서 화살표 생략 — 방향성 시각 필수
- ❌ 상태 pill 아웃라인/채움 규칙 반전 — 진행 전=아웃라인, 완료=채움 방향 고정
- ❌ 섹션 카드 안 CTA를 Large 크기로 — 전체 화면 CTA와 혼동, Medium만 사용
- ❌ 인증 에러 상태 CTA를 Brand 활성으로 유지 — 반드시 회색 채움 disabled
- ❌ 재요청 버튼을 필드 안 어드먼트로 삽입 — 반드시 필드 외부 별도 Small 버튼

## 표준 패턴 — 충전잔액 이용안내 화면 (MYCARD_03)

카드별 이용 내역 조회 화면. 상단 요약(잔액·이번 달 혜택·CTA) + 트랜잭션 리스트 + 하단 세그먼트 탭 구조.

### 화면 구조

액션바(`<` + "이용내역") → 월 선택 헤더 → 카드명·잔액 → 이번 달 요약 카드 → CTA 카드 그룹 → 트랜잭션 리스트(월별 그룹) → **Fixed 하단 세그먼트 탭**.

### 월 선택 헤더

액션바 아래 회색 스트라이프에 `<` YYYY.MM `>` 중앙정렬. 좌우 화살표로 기간 변경, 없는 방향 비활성.

### 잔액 라인 + 확장

좌 라벨(회색) + 우 금액(bold) + **`▽` 확장 화살표**. 화살표 클릭 → 세부 항목 카드 확장(`▽`→`∧`, 대기금·홀딩·휴대폰 충전 등 라벨-값 리스트, 각 라벨에 `?` 도움말 어드먼트).

### 도움말 `?` 어드먼트 아이콘

라벨 우측 원형 outline + `?`. 탭 시 툴팁 or 바텀시트 안내 팝업 (§ "사용법 안내 팝업" 매칭). 특정 용어(대기금·수수료 등) 부가 설명용.

### 이번 달 요약 카드

연보라 카드 배경 (`background/tertiary`), 1~2개 지표 병기:

- **혜택만**: "이번 달 받은 혜택 / 총 {값}원(brand)" + 세부(할인·캐시백)
- **결제금액+혜택**: "이번 달 결제 금액 / 총 {값}원(brand)" + "이번 달 받은 혜택 / 총 {값}원(검정 bold)" + 세부

### CTA 카드 그룹

세로 아웃라인 버튼 (`button/button` `type=gray-line`, 100% 폭) — 부가 조회 진입점. 예: "이전 카드 이용 내역 조회", "지역사랑상품권 이용 내역 조회".

### 트랜잭션 리스트 (충전잔액 이용안내)

**§ "트랜잭션 리스트 아이콘 원 6종" + § MY_DETAIL 트랜잭션 리스트와 동일 구조**.

- 월별 그룹 헤딩 "MM/DD" (bold 검정)
- 아이템: 좌 원 아이콘(6종) + 중 유형(bold) + 매장명·`{HH:MM}` (회색 caption) + 우 금액(bold) + 상태 텍스트 (brand=정상 / red=취소·회수)
- 해외거래: 우측 상단 "{국가코드} {거래유형}" 병기, 외화 통화(SGD·JPY 등) 표기
- 유형 다양화: 결제·결제취소·환불·충전·충전취소·자동충전·돈 옮기기 from/to 카드·해외ATM출금·무승인환급·무승인매입·미지정거래
- 서브 텍스트: `{결제수수료}`, `{취소수수료}`, `{자동취소}`, `{자동결제}` 등 세부 병기

### 트랜잭션 아이템 좌 스와이프 액션

좌 스와이프 → 우측 휴지통 노출 (`background/quaternary` + `ic_trash`). 탭 시 숨기기·삭제.

### 카드 정보 헤더 (구 카드 상세용)

상단 상태 pill(연보라 채움, "분실신고카드"·"자동 충전 중" 등, § 상태 pill 5종 "현재 활성/연결" 매칭) + 카드명(bold) + 정보 카드(카드번호 마스킹·이용기간 등 라벨-값).

### 부분 빈 상태 (상단 요약 유지)

**리스트 섹션만 빈 상태, 상단 요약·헤더는 유지** (3번째 유형). 문서+X 아이콘 + 헤딩 1줄, CTA 없음.

**빈 상태 아이콘 컨텍스트별**: 상품·검색 없음 = **gift+X** / 내역·리스트 없음 = **문서+X**.

### 하단 배치 세그먼트 컨트롤 탭

- MYCARD_03의 카드/포인트 뷰 전환 = 세그먼트 컨트롤 **하단 배치 variant** (트랙 없음, brand 채움 pill 활성). 상세 비교는 § "병렬 탭 pill vs 세그먼트 컨트롤 탭 구분" 참조.
- **§ QUICK 하단 pill 탭과 차이**: QUICK = 동적 라벨(상품명 실 값) / 세그먼트 하단 = 고정 라벨.

### 카드 캐시(CCP) 이용내역 확장 (§ 아래 CCP 화면과 연계)

MYCARD_03의 카드 캐시(포인트) 뷰. § "하단 배치 세그먼트 컨트롤 탭"의 "포인트" 뷰 진입 후 화면.

- **포인트 유형 선택 드롭다운**: 카드명 아래 중앙 "식비지원 포인트 ▽" — 여러 포인트 계좌 중 선택. § "정렬 드롭다운"(우상단)과 다른 **중앙 배치 라벨형** 드롭다운.
- **포인트 잔액 라인**: 좌 라벨(회색) + `ⓘ` 도움말 아이콘 + 우 값 "**200,000P**" (bold, **P 단위 = 포인트**)
- **탭 pill 병렬 2개** (내역 요약 / 소멸 예정): 활성 = brand 채움 + 흰 텍스트 / 비활성 = 연보라 배경 + brand 텍스트. 화면 폭 균등 분할.
  - 탭 라벨 좌측에 **red `!` 알림 인디케이터** 조건부 (해당 탭에 확인 필요 아이템 있을 때)
- **리스트 필터 드롭다운**: 우상단 "전체 ▽" — § "정렬 드롭다운" 매칭
- 트랜잭션 리스트는 § "트랜잭션 리스트 6종 아이콘" 규칙 재사용

### 도움말 아이콘 2 variant 구분

| 아이콘 | 스타일 | 위치·용도 |
|---|---|---|
| **`?` outline** | 원형 회색 outline + `?` | 라벨 우측 어드먼트, **특정 용어 부가 설명** (충전잔액 이용안내의 대기금·수수료 등) |
| **`ⓘ` 회색 채움** | 원형 `background/quaternary` 회색 채움 + i | **잔액·상태 정보 안내** (포인트 잔액 등) |

두 아이콘 공통: 탭 시 툴팁 or 바텀시트 안내 팝업 (§ "사용법 안내 팝업" 매칭). 미세 구분 확정 유예.

### 병렬 탭 pill vs 세그먼트 컨트롤 탭 구분

| 유형 | 스타일 | 용도 |
|---|---|---|
| **세그먼트 컨트롤 (상단)** | 트랙 배경 + 흰 카드 활성 | 상태 필터 (사용 가능·완료) |
| **세그먼트 컨트롤 (하단)** | 트랙 없음, brand 채움 pill 활성 | 뷰 전환 (카드/포인트) |
| **병렬 탭 pill** | 활성 = brand 채움 / 비활성 = 연보라 배경 (**둘 다 채움**) | 리스트 종류 전환 (내역 요약/소멸 예정) + 알림 인디케이터 조건부 |

병렬 탭 pill 특징: 트랙 없이 두 pill 병렬, 비활성도 채움 (아웃라인 아님).

### 트랜잭션 상세 팝업

트랜잭션 리스트 아이템 클릭 시 열리는 바텀시트 상세 팝업.

- **헤딩**: 상단 라벨(예: "{포인트 지급}" 회색) + 큰 값 (bold) — **값 색 규칙**: `+` 부호(적립·지급) = **brand 보라** / `-` 부호(사용·차감) = **red** (§ `accent/primary` 6용도 ⑤ 매칭)
- **정보 카드**: 회색 배경 안 라벨(회색)-값(bold 검정) 리스트
  - 성격별 항목 다름:
    - 적립·지급: 일시·가맹점·유형·사유·유효기간 (5개)
    - 사용·차감: 일시·유형·사유 (3개, 가맹점·유효기간 생략)
    - 포인트 전환: 일시·유형·**전환카드**·유효기간
- **하단 CTA**: "확인" (Large Brand)

### 요약 팝업 카드 안 divider 구조

트랜잭션 요약 팝업(예: 월별 지급/사용 요약)에서 **최근 기간 vs 누적 기간** 구분용 얇은 divider:

- 상단: "N월 지급/적립" · "N월 사용" 라인
- 얇은 divider
- 하단: "YYYY년 총 지급/적립" · "YYYY년 총 사용" 라인

라벨-값 리스트 안 divider로 두 기간을 시각적 분리.

### 조회 시각 안내

정보 팝업·화면 하단에 "YYYY/MM/DD HH:MM 기준으로 조회된 내용입니다." (회색 caption 중앙정렬) — 실시간이 아님을 알림. CTA 위에 배치.

### 이용안내 페이지 표준 구조 (WEL 등)

서비스·기능 이용안내 페이지 표준.

- **액션바**: `<` 없이 우 `×` 닫기 (모달성)
- **상단 일러스트 영역**: 그라디언트 배경 + 아이콘·일러스트 (예: 손·₩)
- **헤딩**: "{서비스명} 유의사항" (bold 검정)
- **유의사항 bullet 리스트**: `● ` 접두어 (§ 유의사항 리스트 매칭)
- **§ "약관 상세 페이지"와 다름**: 약관 = 법령·조항 나열 (긴 텍스트) / 이용안내 = 요약 유의사항 (bullet)

### 안티패턴 (하지 말 것 — CCP·이용안내)

- ❌ 포인트 잔액 단위를 "원"으로 — 반드시 **P (포인트)**
- ❌ 탭 pill 병렬에서 두 pill 다 아웃라인 — 반드시 활성=brand 채움, 비활성=**연보라 배경 채움**
- ❌ 트랜잭션 상세 팝업 헤딩 값 색을 부호와 반대로 — `+` = brand / `-` = red 고정
- ❌ 요약 팝업에서 최근·누적 구분 없이 하나의 리스트로 — 반드시 얇은 divider 삽입
- ❌ 조회 시각 안내 위치를 상단으로 — 반드시 CTA 위 하단 caption
- ❌ 이용안내 페이지에 하단 CTA "확인" 추가 — 액션바 `×`로만 닫음

### 안티패턴 (하지 말 것 — 충전잔액 이용안내)

- ❌ 잔액 라인에 확장 화살표 없이 세부 항목 항상 노출 — 반드시 `▽`/`∧` 확장 트리거
- ❌ 도움말 `?` 아이콘을 라벨 좌측이나 별도 라인에 — 반드시 라벨 우측 어드먼트
- ❌ 이번 달 요약 카드에 결제 금액·혜택 색 반전 — 결제 금액=brand, 혜택 세부 값=검정 bold
- ❌ 트랜잭션 아이콘 6종 규칙 벗어난 커스텀 색 — 반드시 § 6종 규칙 준수
- ❌ 하단 세그먼트 탭을 상단으로 이동 — 뷰 전환은 하단, 사용 가능·완료 같은 상태 필터는 상단
- ❌ 부분 빈 상태에서 상단 요약도 함께 제거 — 컨텍스트 유지 필수

## 표준 패턴 — 코나카드 홈 화면 (KONACARD_HOME)

앱 진입 홈 화면. 카드 유형(럭키·트래블K·법인·복지·EXPAT 등)·상태(카드없음·관리자정지·포인트비활성화 등)별로 다양한 variant. 상단 카드 캐러셀 + 다양한 하위 섹션 구성.

### 홈 상단 헤더바 (액션바 대체)

일반 액션바 대신 홈 전용 헤더바.

- **좌**: 원형 아바타(개인화) + 감성 안내 텍스트 (예: "럭키로코 참여해보세요:)")
- **우**: 알림 아이콘 `🔔` + 햄버거 메뉴 아이콘
- **§ 일반 액션바와 구분** — 액션바 = 스택형 화면 / 헤더바 = 홈 전용, 아바타·개인화 콘텐츠 포함
- **상태별 좌측 요소 변화**:
  - 정상: 아바타 + 감성 텍스트
  - 카드없음: 카드+`+` 아이콘 + "코나카드를 등록해주세요!"
  - 관리자정지 등 제한 상태: **KONA 워드마크만** (개인화 안내 제거)

### 메인 카드 (신용카드 UI)

카드 캐러셀 안 각 카드 아이템.

| 요소 | 위치·스타일 |
|---|---|
| 카드 유형 pill (조건부) | 우상단 여러 개 병렬 — "용돈 카드", "분실신고 완료", "관리자 정지", "재발급신청 완료", "MO·NA" 등 |
| 카드명 + 뒷자리 | 좌상단 "럭키유카드 퍼플 \| 2490" |
| 실물 카드 이미지 | 우측, 실물 카드 렌더 |
| 잔액 라벨·값 | 좌: "충전 잔액" (회색) / 값: bold 크게 + **`▷` 상세 진입 화살표** |
| `⋮` 더보기 메뉴 | 우상단 |
| 하단 액션 2개 병렬 | **카드 유형별 다름**: 럭키=충전/결제, 트래블K=환전/결제, 관리자정지=관리자에게 문의하세요(Gray Line 단일) |
| 하단 진입 링크 | "카드혜택 보기 >" (얇은 라인) |

**카드 캐러셀 좌우 힌트**:
- 좌측 `+` (카드 추가 진입점)
- 우측 다음 카드 살짝 보임 (좌우 스와이프 가능)
- 카드 여러 개 시 우상단 **1/N 카드 인디케이터**

**추가 정보 pill** (조건부): 메인 카드 안 잔액 위에 "카드포인트 100,000P" 등 부가 잔액 pill 병기 가능.

**잔액 앞 `+` 부호**: 충전·환급 직후 강조 표기 가능 ("+600,000원").

### 카드 상태별 시각 변화 (매트릭스)

| 상태 | 배경 | 헤더 좌측 | 카드 pill | 하단 액션 |
|---|---|---|---|---|
| 정상 | 흰 (일반) | 아바타 + 감성 텍스트 | 카드 유형만 | 충전/결제 or 카드별 액션 |
| 카드없음 | **연보라 (`background/tertiary`)** | 카드+`+` 아이콘 + 안내 | 없음 | 카드 신청 · 카드 등록 pill CTA |
| 관리자정지 | 흰 | KONA 워드마크만 | **"관리자 정지"** pill 추가 | "관리자에게 문의하세요" (Gray Line 단일) |
| 재발급 대기 | 흰 | 정상 유지 | "재발급신청 완료" pill 추가 | 조건별 |

### 요약 정보 카드 (내 캐시·쿠폰·럭키권 등)

- 좌 라벨 - 우 값 여러 라인 (§ MYCARD_03 요약 카드와 유사)
- 값 옆 조건부 어드먼트: 액션 pill (예: "사용"), `N` red 배지 (accent-red NEW), 개수 값 등
- 확장 라인: 아이콘 + 라벨 + 값 + `>` (상세 진입) — 예: "이 달에 받은 코나카드 혜택 | 1,300,000원 >"

### 홈 알림·안내 배너 3종

| 유형 | 좌 아이콘 | 배경 | 성격 |
|---|---|---|---|
| **정보성 진입 배너** | 없음 or 아이콘 | 연보라 (`background/tertiary`) | 만료 임박 · 프로모션 진입 |
| **경고성 알림 배너** | `⚠️` red 원형 채움 | 흰 or 회색 | 정보 업데이트 요청 · 보안 안내 (예: "휴대폰 번호가 바뀌셨나요?") |
| **송금 대기 진입 카드** | 없음 | `background/secondary` 회색 | 조건부 노출 (송금 받을 내역 있음) |

경고성 배너 우측: `×` 닫기 + "확인" 아웃라인 pill 액션.

### 홈 탭 pill (혜택 탭 등)

- 병렬 pill 2개 (예: "무한 혜택" / "카드 혜택")
- 활성 = 아웃라인 + 브라운? or brand / 비활성 = 연보라 채움 + 회색
- **탭 라벨 안 카운트 배지**: 검정 원형 채움 + 흰 숫자 (예: "무한 혜택 【1】") — § "탭 pill red `!` 알림"과 다른 검정 카운트 형식

### 혜택 카드 (좌 헤딩 + 우 아이템 그리드)

- 좌: 헤딩(bold 검정) + "더보기 >" 링크
- 우: 브랜드 혜택 아이템 2~N개 그리드 (브랜드 로고 원 + 텍스트 + 즐겨찾기 아이콘)

### 이벤트 카드 (기획전) 표준 구조

- **NEW 배지** 우상단 (red 채움 pill, § `accent/primary` 6용도 ④)
- 헤딩 (bold 검정, 2줄)
- 기간 (달력 아이콘 + 텍스트)
- 라벨-값 리스트 (1등 상금·진행상태·참여 개수 등)
- 하단 CTA (Medium, 연보라 채움 or brand 아웃라인)
- **하단 인디케이터 도트** (여러 이벤트 슬라이드)

### 진입 배너 (작은 카드)

- 좌: 텍스트 (헤딩·부제·`>`) / 우: 일러스트·이미지
- 배경 색 성격별:
  - 연보라 (`background/tertiary`) — 프로모션·유도
  - 연회색 (`background/secondary`) — 부가 서비스 안내
- 부동산·행복작당 등 제휴사 진입: 좌 헤딩 + 우 브랜드 로고

### 홈 바로가기 아이콘 그리드

- 원형 아이콘 + 하단 라벨, 3~4개 나열 (예: 코나샵·코나몰·송금·전시상)
- **§ 아이콘 밑줄 탭과 다름**: 이건 밑줄 없이 홈 진입점 아이콘, 카테고리 탭 아님

### 코나소식 섹션

- 섹션 헤딩 "코나소식" + 우측 "지난 소식 보기 >"
- 이벤트 배너 (풀 컬러 배경 + 텍스트 + 캐릭터 일러스트)

### 카드 관리 화면 (설정 모달)

카드 캐러셀 `⋮` 더보기에서 진입.

- 액션바: 중앙 "카드 관리" + 우 `×` (모달성)
- 상단 카드 정보 카드 (compact 버전, § "메인 카드"와 유사)
  - 상태 pill 여러 개 병렬 표기 가능
  - 카드 정보 3열: 모바일 카드번호 · 유효기간 · CVC
  - 실물카드번호 라인 + "만료" 등 필드별 상태 pill
- 진입형 리스트 (§ 매칭): 자동 충전·이용 내역·카드혜택·해외 이용 차단·해외 이용 통합 한도·카드명 변경·송금·돈 옮기기·결제 한도·카드 폐기·비밀번호·ATM 감금 해제·분실신고/재발급·교통카드·MONA 요금제·해외 유의사항·카드 안내사항 등

### 카드 유형별 홈 하단 콘텐츠 차별화

같은 홈 구조에서 카드 유형별로 하단 콘텐츠 다름:

- **럭키카드** = 럭키 이벤트 카드 (기획전, 럭키권·클로버 등)
- **트래블K** = 여행 프로모션 배너 + 트래블존 추천 혜택 그리드
- **법인/복지카드** = 법인 전용 안내
- **EXPAT** = 다국어 캠페인 배너

### 안티패턴 (하지 말 것 — 홈 화면)

- ❌ 홈 화면에 일반 액션바(중앙 타이틀) 사용 — 반드시 홈 헤더바 (좌 아바타 + 우 알림·햄버거)
- ❌ 카드없음 상태에서 배경 흰색 유지 — 반드시 **연보라 배경**으로 시각 시그널
- ❌ 관리자정지 등 제한 상태에 개인화 안내 유지 — KONA 워드마크로 대체
- ❌ 카드 유형별 하단 액션을 하드코딩 (예: 트래블K에 "충전") — 카드 성격에 맞는 액션 필수
- ❌ 홈 탭 pill 카운트 배지를 red로 (accent-red NEW와 혼동) — 카운트는 **검정 채움**, red 배지는 알림 인디케이터 용도
- ❌ 카드 상태 pill 여러 개를 세로 나열 — 반드시 가로 병렬
- ❌ 홈 화면 이벤트 카드에서 NEW 배지 위치를 좌상단으로 — 반드시 우상단

## 표준 패턴 — 이용내역 상세 화면 (CARDUSAGE_DETAIL)

이용내역 리스트에서 진입한 개별 트랜잭션 상세. 결제·결제취소·해외거래·모아서 결제 등 유형별로 정보 확장.

### 화면 구조

액션바(`<` 만, 타이틀 없음) → **헤더 정보 카드** → **거래 상세 카드 (3그룹)** → **받은 캐시백 pill 라인** (조건부) → **카드·가맹점 정보 카드** → **모아서 결제 참여자 리스트** (조건부) → **`ⓘ 확인해주세요` 유의사항** → **하단 CTA** (조건부, 취소 가능 시).

### 헤더 정보 카드 (금액 성격별 색)

상단 라벨(회색 caption, "{결제}" 등 거래 유형) + 큰 금액 값 (bold, **성격별 색**).

- **결제·차감·손실** = `font/accent-red` red
- **결제취소·환불·복원·적립** = `font/brand` brand 보라
- § `accent/primary` 6용도 ⑤ (트랜잭션 상태 색) 매칭

### 거래 상세 카드 3그룹 divider 구조

라벨(회색) - 값(bold 검정) 리스트, **얇은 divider로 3그룹 구분**:

1. **거래 메타** — 일시·현지거래일시(해외)·거래유형·거래방식·승인번호
2. **금액 계산** — 요청금액·(해외 시) 환율·외화출금·원화출금·할인금액·사용 쿠폰·사용 카드금액·사용 내 캐시·사용 {카드캐시 전시명}
3. **최종 승인금액** — **라벨·값 모두 `font/brand` 보라 Bold** (강조)

### 라벨-값 안 하위 인덴트 bullet

상위 항목의 세부 브레이크다운을 `●` (small bullet) 하위 인덴트로 표기.

예: "외화출금 금액 {USD} {1.14}" 아래 `●` 외화이용 금액 / `●` 외화이용 수수료

### 라벨에 `?` 도움말 어드먼트 (재확인)

거래방식·특정 라벨 우측에 `?` outline 아이콘 — 클릭 시 § "이용안내 팝업" 열림 (예: "해외이용금액" 팝업).

### 받은 캐시백 pill 라인

거래 상세 카드 아래, 부가 혜택 강조 pill.

- 배경: `background/tertiary` 연보라 채움, 라운드 pill
- 폭: 화면 콘텐츠 폭 100%
- 좌: "받은 캐시백" (검정) + 우: 값 (예: "{+300}원") — brand 보라
- 캐시백 없을 때 생략

### 모아서 결제 참여자 리스트

그룹 결제 트랜잭션 상세의 참여자 목록 섹션.

- 헤딩 좌 "모아서 결제" (bold) + 우 참여자 수 "5명" (bold)
- 참여자 라인: "{이름} ({계좌번호 뒤 4자리}) | {분담 금액}" — 라벨(회색)-값(bold) 스타일
- 얇은 divider로 헤딩과 참여자 리스트 구분

### 트랜잭션 유형별 확장 매트릭스

| 유형 | 헤더 색 | 특이 정보 | 하단 CTA |
|---|---|---|---|
| **결제 (국내)** | red | 기본 |  "가맹점 결제취소" |
| **결제 (해외)** | red | + 국내·현지 거래일시 2줄 + 환율 + 외화·원화 이중 브레이크다운 | "가맹점 결제취소" |
| **결제취소** | brand | 기본 | 없음 |
| **해외 ATM 조회·출금** | red or brand | 환율·외화 정보 | 조건별 |
| **해외 무승인매입·환급** | 상황별 | 무승인 상태 표기 | 조건별 |
| **모아서 결제** | red | + 모아서 결제 참여자 리스트 | "가맹점 결제취소" |
| **송금 (모아서 결제)** | red | + 참여자 리스트, 카드·가맹점 생략 | 없음 (송금 취소 불가) |
| **캐시백·할인** | 상황별 | 원 거래 참조 정보 | 없음 |

### 안티패턴 (하지 말 것 — 이용내역 상세)

- ❌ 헤더 금액 색을 부호와 반대로 — 결제=red, 결제취소=brand 고정
- ❌ 거래 상세 카드에서 divider 없이 하나의 리스트로 — 3그룹 divider 필수
- ❌ 최종 승인금액을 검정으로 — 반드시 brand 보라 강조
- ❌ 하위 인덴트 없이 외화·원화 브레이크다운 병기 — 반드시 `●` 하위 인덴트
- ❌ 받은 캐시백 pill을 카드 사각 배경으로 — 반드시 라운드 pill
- ❌ 모아서 결제 참여자 리스트에 divider 없이 헤딩과 참여자 병합 — 얇은 divider 필수

## 권장 패턴 — "카드 대상 상태 해제 액션" 3화면 구조 (참고용)

CVC 인증오류 해제, ATM 출금 잠금 해제처럼 **카드에 걸린 특정 제한을 푸는** 성격의 액션에 권장하는 표준 구조. 강제 규칙은 아니지만 유사 상황엔 이 3화면 세트를 따르면 일관성 확보.

| 1. 대상 카드 선택 | 스택형 진행 | 헤드라인(핵심 액션 강조) + 부가 설명(옵션) + 선택형 리스트 카드(우측 √ 체크) + `● 확인해주세요.` 유의사항 + CTA "{액션}하기" |
