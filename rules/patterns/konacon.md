# 화면 패턴 — 코나콘 (커머스 · 기프티콘)

> `konacard-ds-rule.md` 에서 옮겨 온 화면별 표준 패턴. 공통 규칙(화면 성격 분류 · 색 · 글자 · 간격 · 톤앤매너 · 하지 말 것)은 `konacard-ds-rule.md`, 다른 패턴은 같은 폴더의 다른 파일에 있음. 문서 안 § 참조는 이름으로 찾으면 됨.

## 표준 패턴 — 커머스·서비스 진입·목록 화면 (기프티콘 KONACON)

브랜드/상품을 카탈로그로 탐색하고 구매·사용하는 서비스의 진입/목록 화면. 커머스 성격 서비스 재사용 가능.

### 화면 배치 (상→하)

- **Fixed 상단**: 액션바(우 pill 액션) → 검색 필드 → (조건부) 알림 배너 → 기획 배너 → 카테고리 탭 → (조건부) 서브 카테고리 pill → (조건부) 정렬 트리거
- **Scroll 콘텐츠**: 개인화 섹션(가로 스크롤 카드) + 큐레이션 섹션(2열 그리드)
- **Fixed 하단**: 하단 CTA (Large Brand) + 위로가기 fab (floating)

각 요소 상세는 아래 서브섹션.

### 액션바 우측 pill 액션

- 기존 액션바 우측 요소(텍스트 링크 or `×`)에 **pill 아웃라인 액션** 추가.
- 구조: 라운드 pill 아웃라인 + 좌측 아이콘 + "라벨" 텍스트
- 예: 티켓 아이콘 + "보관함" — 서비스 별도 진입점을 액션바 우측에 상시 노출.
- 스타일: 테두리 `color/button/tertiary` #DDDDDD, 높이는 고정값이 아니라 상하 padding 8+8 기반 가변(38), 좌우 padding 12, 아이콘 20 + gap 6 + `body/2-Bold` 라벨
- **사용 조건** — 커머스·서비스 성격 화면에서 "장바구니·보관함·마이" 같은 상시 진입점이 필요할 때. 일반 스택형·조회 화면은 기존 텍스트 링크 유지.

### 상단 고정 검색 필드

- 위치: 액션바 바로 아래, 화면 상단 스크롤 무관 노출
- 구조: 검색 입력 필드 (라운드 rectangle) + placeholder + 우측 돋보기 아이콘
- placeholder 예: "상품을 찾아보세요"
- 탭 시 검색 화면 진입 (별도 검색 화면 활성 — § SEARCH 그룹 규칙 예정)
- **일반 스택형·조회 화면과 구분** — 이 검색 필드는 커머스·목록 성격 화면 전용 상시 진입점.

### 만료 임박 알림 배너

특정 조건(만료 임박, 미사용 코나콘 등)이 있을 때만 노출하는 진입 유도 배너.

| 요소 | 스타일 |
|---|---|
| 배경 | `background/tertiary` (`#F8F6FE`, 연보라) 라운드 카드 |
| 좌측 아이콘 | 원형 (자물쇠·시계 등) — 상황 성격 표현 |
| 중앙 텍스트 | Bold 검정 헤딩 1줄 + 회색 서브 1줄 |
| 우측 카운트 배지 | `accent/primary` red 원 + 흰 텍스트 (예: "2") |
| 클릭 진입 | 관련 리스트 화면 |

- **red 카운트 배지** — § "`accent/primary` 6용도 규칙" 관찰 확장 후보 (알림 카운트).

### 기획 배너 (프로모션 카드)

- 라운드 rectangle 카드, 화면 폭 100% (좌우 20 margin)
- **좌측 텍스트 영역**: 배지 pill(예: "기획전") + 헤딩 2줄 (Bold 검정) + CTA 텍스트 링크("자세히보기 >")
- **우측 이미지 영역**: 상품·일러스트 이미지
- **하단 인디케이터 도트** — 여러 배너 슬라이드일 때만, 우하단 배치. 활성 도트 = 검정, 비활성 = 회색.
- 슬라이드 가능 (좌우 스와이프)
- 배지 pill 스타일: 회색이 아니라 **브랜드 컬러(보라·빨강) 또는 배너 맥락에 맞는 커스텀 색 + 흰 텍스트**

### 아이콘 밑줄 탭 (원형 아이콘 + 라벨 2줄)

기존 § "탭 (Tab)" 밑줄 스타일에 아이콘이 필수로 붙는 확장 variant.

| 요소 | 스타일 |
|---|---|
| 각 탭 | 아이콘 + 하단 라벨 텍스트 (2줄 세로 구성) |
| 아이콘 | 원형 배경 없음 — 아이콘 자체가 36×36 캐릭터성 일러스트(별·도넛·피자 등) |
| 라벨 | `body/2-Bold` — 활성=`font/brand` 보라 + Bold, 비활성 `font/tertiary` #666666 Regular |
| 활성 표시 | 하단 밑줄 (2px, `color/background/brand`) |
| 스크롤 | 가로 스크롤, 좌우 끝 fade-out |

- **일반 밑줄 탭과 구분** — 아이콘 없는 밑줄 탭 = 필터·뷰·카테고리 (`konacard-ds-rule.md § "탭 (Tab)"`). **아이콘 밑줄 탭 = 커머스·서비스 최상위 카테고리 선택 전용.**
- 대분류 카테고리를 시각적으로 구분해야 할 때만 사용.

### 서브 카테고리 pill 그룹

대분류 탭(아이콘 밑줄 탭)을 선택했을 때, 그 안의 세부 카테고리(브랜드·시리즈)를 pill로 나열.

- 위치: 아이콘 밑줄 탭 아래
- 스타일: 기본 상태는 **흰 배경**(`background/primary`) + 옅은 테두리(`border/primary`) + `font/tertiary` 회색 텍스트
- 선택 시: **연보라 채움**(`color/button/secondary` #F4F0FD, 아웃라인 없음) + `font/brand` 보라 텍스트
- 가로 스크롤, 좌우 끝 fade-out
- **§ "Pill 배지 (3색 통합 규칙)" 과 구분** — 배지 = 정보 표시(비클릭). 서브 카테고리 pill = **필터 선택형(클릭 가능)**.

### 정렬 드롭다운

리스트/그리드 우상단 정렬 트리거. "할인 순 ▼" 텍스트+아이콘 → 탭 시 화면 안 즉시 열리는 lightweight 옵션 카드 (모달·바텀시트 아님). 옵션 예: "할인 순 / 판매량 순 / 가격 순". 예시 화면: KeyScreen `10934:7290` (코나콘 메인).

- **트리거**:
  - 텍스트 `body/2-Regular` 14/22 `color/font/tertiary` #666 + `ic_arrow/ic_arrow_down_12_g` 12×8, gap 4 (`spacing-2xsmall`)
  - 우측 정렬, 영역 padding 상하 12(`spacing-small`)·좌우 20(`spacing-large`) → 높이 46
- **옵션 카드**:
  - 폭 96, 테두리 1px #EBEBEB(토큰 미바인딩), radius 8(`radius-small`), **그림자 없음**, 배경 `color/background/primary`
  - 옵션 1줄 38 = padding 상하 8(`spacing-xsmall`)·좌우 12(`spacing-small`) + 텍스트 22, 가운데 정렬
  - 옵션 사이 구분선 1px #EBEBEB (마지막 줄 제외)
  - 기본 옵션: `body/2-Regular` 14 `color/font/tertiary` #666
  - **선택된 옵션: 배경 `color/background/secondary` #F8F9FB + `body/2-bold` #666** (보라 아님)
  - 위치: 트리거 바로 아래(4px 겹침), 우측 끝을 화면 여백 20에 맞춤, 아래 리스트 위에 겹쳐서 열림

### 상품 카드 표기 규칙 (커머스 공통)

상품 그리드/리스트 카드 안 텍스트 위계 표준.

| 항목 | 스타일 | 색 |
|---|---|---|
| 브랜드명 | `caption/1-Regular` 12/18 | `font/tertiary` 회색 |
| 상품명 | `body/2-Bold` 14/22 (1~2줄) | `font/primary` 검정 |
| 할인율 (%) | `body/2-Bold` 14/22 | `font/brand` 보라 |
| 가격 (원) | `body/2-Bold` 14/22 | `font/primary` 검정 |

- 위계 순서: 브랜드명(작고 회색) → 상품명(bold 검정) → 할인율 + 가격 (같은 줄, 할인율 강조)
- 할인율은 **가격 앞에 병기** (예: "18% 3,000원") — 할인이 강조 포인트
- **원가 취소선 표기 (선택)**: 브랜드머니 사례 확장 — "**10%** ~~50,000원~~" (`accent/primary` red 할인율 케이스에서 관찰). 코나콘 상품 카드는 원가 없이 할인율만.

### 상품 배지 2종 (커머스 상품 카드용) — 배치별 색 규칙

상품 카드 프로모션 배지 2종. **배치에 따라 BEST 색이 달라짐**.

| 배지 | 그리드 오버레이 (이미지 좌상단) | 리스트 위치 (상품명 옆·위) |
|---|---|---|
| **BEST** | `accent/primary` red 채움 + 흰 텍스트 | `background/tertiary` 연보라 채움 + `font/brand` 텍스트 |
| **오픈이벤트** | `background/tertiary` 연보라 + `font/brand` | 동일 (배치 무관 통일) |

- **BEST 배치별 이유**: 그리드 오버레이 = 이미지 안 시각 강조 필요(red) / 리스트 = 텍스트와 조화(연보라)
- 스타일: 작은 라운드 pill, 상하좌우 padding 8 (`spacing-xsmall`)
- **배치 판단**: 이미지 우선 그리드 = 이미지 좌상단 오버레이 / 정보 우선 리스트 = 우측 정보 상단
- **§ "Pill 배지 (3색 통합 규칙)"과 구분**: 카드 배경 붙는 배지 vs. 상품 프로모션 배지 (다른 관점)

### 위로가기 fab (Floating Scroll-Top)

긴 스크롤 화면에서 최상단으로 즉시 이동하는 floating 액션.

| 속성 | 값 |
|---|---|
| 형태 | 원형 흰 배경 (`background/primary`) |
| 크기 | 48×48 |
| 아이콘 | `ic_arrow_up` (라인 스타일, 검정) |
| 그림자 | 옅은 elevation |
| 위치 | 우하단, 우측 20 / 하단 CTA 위 여백 20px ("UI/Floating" 래퍼 자체의 상하좌우 `layout/margin` 패딩값 — fab 전용 간격이 아니라 공통 레이아웃 마진) |
| 등장 조건 | 일정 스크롤 이상 내려갔을 때만 표시 |

- 하단 CTA와 함께 사용 시 CTA 위에 겹치지 않도록 위치.
- **Toast(하단 40)와 위치 관계** — Toast가 뜰 때는 위로가기 fab을 잠시 숨기거나 위로 밀기 *(관찰 미확인, 확정 필요)*.

### 빈 상태 (KONACON 확장)

기존 § "빈 상태 (Empty State)" 규칙의 커머스 화면 예외 (**하단 CTA 유지**).

- 중앙 회색 라인 아이콘 + X 오버레이 원 + Bold 검정 안내(2줄) + 하단 CTA 유지 (다른 진입점 유도)
- 예: "아직 {카테고리명} 상품들을 / 판매 준비하고 있어요."
- § "빈 상태 3종 통합 구분 규칙" 매트릭스에서 3종 비교

### 개인화·큐레이션 섹션 구조

- **섹션 헤더** — Bold 검정 헤딩 (예: "다시 구매해요?", "요즘 잘나가는 코나콘"). `heading/2-bold` 사이즈, 20 상단 여백.
- **개인화 섹션** (최근·자주 구매): 가로 스크롤 카드 리스트
- **큐레이션 섹션** (베스트·이벤트): 세로 2열 그리드
- **섹션 사이 여백**: 별도의 "섹션 갭" 값이 아니라 **섹션 헤딩 컴포넌트(`heading/3-bold`)가 상하 24px(spacing-xlarge) 패딩을 자체 내장**하고 있고, 그게 섹션 간 시각적 간격을 만드는 구조. 단, 다른 화면·다른 디자이너가 만든 섹션에서는 이 패턴을 안 따랐을 수 있음.

### 안티패턴 (하지 말 것 — KONACON 진입 화면)

- ❌ 액션바 우측 pill 액션에 배경 채우기 — 반드시 아웃라인만
- ❌ 상품 카드에서 할인율을 검정, 가격을 보라로 반전 — 항상 할인율=brand, 가격=검정
- ❌ BEST 배지를 pill 배지 3색(진한 보라·옅은 보라·회색)으로 대체 — BEST는 반드시 accent-red
- ❌ 서브 카테고리 pill을 여러 줄 wrap — 반드시 가로 스크롤 1줄
- ❌ 아이콘 밑줄 탭에 아이콘 생략 — 대분류 카테고리 시각 구분 목적이므로 아이콘 필수

## 표준 패턴 — 개인 보관 목록 화면 (내 코나콘 등)

MAIN에서 진입한 개인 보관·소유 성격의 목록 화면. 커머스 진입(MAIN)과 대비되는 서브 스택.

### 화면 구조

액션바(`<` + 타이틀 + 우측 텍스트 링크) → 세그먼트 컨트롤 탭 2탭 → 리스트 or 빈 상태

### 개인 보관 목록 리스트 카드 (예: 코나콘 목록)

예시 화면: KeyScreen `10180:14968` (내 코나콘).

| 영역 | 요소 |
|---|---|
| 좌 (64×64) | 상품 이미지 — radius 8(`radius-small`), 배경 `color/background/secondary` #F8F9FB, 세로 중앙 — 사용 완료 시 dim 처리 |
| 우 상단 | 브랜드명 — 로고 16×16(원형) + gap 4 + `body/3-Regular` 12/18 `color/font/tertiary` |
| 우 중단 | 상품명 (`body/1-Bold` 15/24 검정, 1~2줄 "..." 말줄임) |
| 우 하단 | **D-day 카운트** (`body/3-Regular` 12/18 `color/font/tertiary`) — "D-2", "D-365" |
| 우측 배지 (조건부) | 상태 pill 5종 중 해당 상태 — 텍스트 묶음과 **세로 중앙 정렬**, 텍스트와 gap 8 (예: "만료 예정" `color/label/accent-red`) |

- 카드 padding 상하 16(`spacing-medium`)·좌우 0, 이미지 ↔ 텍스트 gap 16(`spacing-medium`), 텍스트 줄 간 gap 0
- 카드 높이: 상품명 1줄 96 / 2줄 116
- 카드 사이 `line/solid` 1px
- 클릭 → 상세 화면(§ MY_DETAIL 규칙 예정)

### 구매 내역 리스트 카드 (거래 기록 성격)

| 영역 | 요소 |
|---|---|
| 좌 (64×64) | 상품 이미지 (컬러 유지 — 취소된 것도) |
| 우 상단 | 브랜드명(로고 + 회색 caption) |
| 우 중단 | 상품명 (bold 검정, 1~2줄 "..." 말줄임) |
| 우 강조 | **가격 (`body/1-Bold` 검정, 크게)** — 예: "50,000원" |
| 우 부가 | 수량(선택, 1개 초과일 때만: "2개") + 구매 일자 (`font/tertiary` 회색 caption) |
| 우 상단 배지 | **이상 상태만** 노출 (예: "구매 취소" red · "부분 취소" 회색) — 정상 구매는 배지 없음 |

- 개인 보관 목록 카드와 다른 강조점: **가격이 강조 (bold 크게)** — 거래 기록이므로 금액이 핵심 정보
- 개인 보관 목록 = 사용 가능성/D-day 강조 / 구매 내역 = 금액·일자 강조

### D-day 카운트 표기

- 형식: `D-{N}` (예: "D-2", "D-365")
- 스타일: `font/tertiary` 회색 `caption/1-Regular`
- 위치: 상품명 아래
- **D-1 이하일 때 우상단 "만료 예정" pill(red) 병기** (관찰 사례)

### 세그먼트 탭 비활성 개수 병기

- 비활성 탭 라벨에 개수 표기 (예: "사용 가능 3개")
- 활성 탭에는 개수 생략 (관찰상 활성 탭엔 개수 없이 라벨만)
- 사용자에게 다른 탭 상태의 물량 알림 목적
- **§ "세그먼트 컨트롤 탭 상세" 확장** — 카운트 병기 시 텍스트에 " {N}개" 접미로 붙임

### "더보기 ∨" 페이지네이션 링크

예시 화면: KeyScreen `10180:15033` (내 코나콘 10개 이상).

- 위치: 리스트 하단 중앙정렬 — 마지막 카드 아래 16, 링크 아래 padding 32(`spacing-2xlarge`)
- 구조: "더보기" 텍스트 + `ic_arrow/ic_arrow_down_12_g` (12×8, ∨), gap 4 (`spacing-2xsmall`)
- 스타일: `body/2-Regular` 14/22 `color/font/tertiary` #666 — § "정렬 드롭다운" 트리거와 같은 텍스트·아이콘·간격
- 마지막 카드 아래 구분선은 숨김
- **인피니트 스크롤 아닌 명시적 클릭** — 사용자가 요청해야 다음 페이지 로드
- 리스트 처음 10건 노출 후, 초과분은 "더보기"로 확장

### 사용 완료·만료 이미지 dim 처리

- 사용 완료된 아이템 이미지는 opacity·필터로 회색톤 dim 처리
- 시각적으로 "이미 소진됨" 표현
- 상태 pill(brand fill "사용 완료" 또는 gray fill "유효기간 만료")과 짝

### 개인 보관 목록 빈 상태 (커머스 목록과 대비)

- **CTA 없음** — § "빈 상태 (Empty State)" 원칙 유지
- 회색 아이콘(gift + X 오버레이) + Bold 검정 헤딩(1줄) + 회색 부가 안내(2~3줄)
- 부가 안내 텍스트에 **다른 진입점 힌트** 포함 (예: "우상단의 필터를 눌러...", "구매 내역을 눌러...")
- **커머스 목록(MAIN)의 CTA 유지 예외와 대비** — MAIN=커머스 진입 CTA 유지 / MY=개인 보관 CTA 없음

### 안티패턴 (하지 말 것 — MY/개인 보관 목록)

- ❌ 개인 보관 목록의 액션바 우측에 pill 액션 사용 — pill은 서비스 진입점(MAIN)에만
- ❌ 구매 내역 카드에서 가격 생략 — 거래 기록이므로 금액 강조 필수
- ❌ 사용 완료된 이미지도 원본 컬러 유지 — 반드시 dim 처리
- ❌ 개인 보관 목록 빈 상태에 CTA 추가 — 커머스 목록과 혼동, 원칙대로 안내만
- ❌ D-day를 "3일 남음" 같은 서술형으로 — 반드시 "D-N" 축약형

## 표준 패턴 — 아이템 상세 화면 (내 코나콘 상세 등)

리스트에서 진입한 개별 아이템 상세. 사용 인증 요소(바코드·코드) + 아이템 정보 + 부가 정보(사용법·주의사항)로 구성. 모달성 성격.

### 화면 구조

액션바(좌 없음 + 타이틀 + 우 `×`, 모달성) → 상품 정보 카드 → 하단 액션 영역 → 아코디언 부가 정보 → 하단 유틸리티 안내

### 상품 정보 카드 위계

카드 내부 상→하 순서:

| 순서 | 요소 | 스타일 |
|---|---|---|
| 1 | 브랜드명 | `body/2-Regular` 회색 or 로고+텍스트 |
| 2 | 상품명 | `heading/2-bold` 검정 (중앙정렬) |
| 3 | 유효기간 | "YYYY.MM.DD까지", `caption/1-Regular` 회색 |
| 4 | (조건부) **사용 불가 인라인 알림** | `ⓘ` red 원 + `font/accent-red` red 텍스트 |
| 5 | 상품 이미지 | 큰 이미지 (라운드 rectangle 안), 사용 완료·만료 시 dim |
| 6 | **바코드 인증 영역** (§ "바코드 인증 카드") |
| 7 | (조건부) **하단 액션 페어** (§ "하단 액션 페어 vs 하단 고정 CTA") |

### 바코드 인증 카드

사용 인증(오프라인·매장 제시)용 코드 표시 영역.

- **inumber 로고** — 연보라 텍스트 (상단, 라인 좌 or 중앙)
- **바코드 스트라이프 이미지** — 검정 라인 조합, 화면 폭 넓게
- **코드 텍스트 + 복사 아이콘**:
  - 코드: 숫자 나열 (예: "1111222233334444"), 중앙정렬
  - 우측 `ic_copy` 아이콘 — 탭 시 클립보드 복사
- 위치: 상품 이미지 아래

### 하단 액션 페어 vs 하단 고정 CTA (상황별)

상세 화면 하단 액션 배치는 **아이템 상태·가능한 액션**에 따라 두 방식 중 선택:

| 방식 | 언제 | 구성 |
|---|---|---|
| **하단 액션 페어** (카드 내부 하단) | 일반 상태 (전달·다운로드 가능) | 좌: 넓은 아웃라인 버튼("다른 사람에게 전달하기") + 우: 좁은 아이콘 버튼(다운로드) — **비율 약 8:2**(전체 280px 중 좌 232px + 우 40px + gap 8px) |
| **하단 고정 CTA** (화면 하단 fixed) | 특정 액션 트리거 필요 (예: 유효기간 연장 가능) | Large Brand 채움 CTA — "유효기간 연장" 등. 카드 안 액션 페어 대신 노출 |
| **회색 채움 CTA** (조건부 disabled 유사) | 액션 트리거 가능하지만 결과 조건부 (예: 취소 가능 여부 확인 필요) | 회색 배경 CTA + 어두운 텍스트. 아래 유틸리티 안내 텍스트로 조건 힌트 |

- **하단 액션 페어의 아웃라인 스타일**: `border/*` 아웃라인 (`button/button` `type=gray-line` 계열, brand 아님) — 부가 액션 성격 강조
- 두 방식 병존 금지 (액션 페어와 고정 CTA 동시 노출 X)

### 상품권 상세 확장 (잔액·사용 내역 요소)

일반 코나콘과 달리 **여러 번 사용 가능한 상품권**은 추가 요소 필요.

- **잔액 카드** (상품 정보 카드 아래, 별개 카드):
  - 좌: "잔액" (검정 `body/1-Regular`)
  - 우: 금액 (예: "49,000원") — `font/brand` 보라 Bold
  - 사용 가능 상태에서만 brand 강조, 만료·사용불가 시 회색 다운그레이드 — 브랜드머니 상품 상태 배지(기본/사용완료=brand 보라, 환불대기/환불완료=neutral-tertiary 회색)와 동일한 원리
- **사용 내역 섹션** (잔액 카드 아래):
  - 섹션 헤딩 "사용 내역" (bold 검정)
  - 트랜잭션 리스트 (§ "트랜잭션 리스트 (사용 내역)")
  - 리스트 하단 "내역 더보기" 회색 pill 버튼

### 트랜잭션 리스트 (사용 내역)

각 트랜잭션 아이템 구조:

| 위치 | 요소 | 스타일 |
|---|---|---|
| 좌 상단 | 매장명 | `body/1-Bold` or `body/2-Bold` 검정 |
| 좌 하단 | 사용 일시 (YYYY.MM.DD HH:MM:SS) | `caption/1-Regular` 회색 |
| 우 상단 | **금액 (±부호)** | `body/1-Bold` 검정, +/- 부호 병기 |
| 우 하단 | 상태 라벨 | `body/2-Regular` 색 텍스트 (§ 아래) |

- **± 부호 규칙**:
  - `-` = 정상 사용(잔액 차감)
  - `+` = 사용 취소(잔액 복원)
- **상태 텍스트 색** (§ `accent/primary` 6용도 ⑤ 매칭):
  - "사용" = `font/brand` 보라
  - "사용 취소" / "부분 취소" = `font/accent-red` red
- 아이템 사이 divider 없음, 여백만

### "내역 더보기" 회색 pill 버튼 (섹션 안 부분 확장)

리스트 하단 중앙정렬, `background/quaternary` 회색 채움 pill + `font/tertiary` 텍스트. 대량 이력은 § "사용 내역 전체 목록 화면"으로 이동.

- **§ "더보기 ∨" 페이지네이션과 차이**: "더보기 ∨" = 텍스트 링크 (전체 확장) / "내역 더보기" pill = 배경 있는 pill (섹션 안 부분 확장)

### 사용 내역 전체 목록 화면 (별도 모달)

액션바(× 닫기) + **월별 그룹 헤딩** "YYYY년 M월" (bold 검정, 각 월 상단) + 트랜잭션 리스트. 월 그룹 사이 여백 **32px**. CTA 없이 스크롤만.

### 사용 불가 인라인 알림

상세 헤더에 만료·사용불가 인라인 표기. 유효기간 텍스트 아래에 `ⓘ` red 원형 아이콘 + red 텍스트 (예: "사용할 수 없는 코나콘이에요"). 상태 pill(우상단)과 달리 헤더 인라인. § `accent/primary` 6용도 관찰 확장 후보.

### 아코디언 부가 정보 4섹션 (표준 순서)

1. 사용 가능 매장 (기본 확장)
2. 제한사항 (접힘)
3. 주의사항 (접힘)
4. 상품 고시 정보 (접힘)

유효기간 연장 가능 아이템은 **"환불/취소 안내"** 섹션 추가. § "아코디언 리스트 (`accordion`)" 규칙 따름.

### 하단 유틸리티 안내 텍스트

최하단(아코디언 아래) `caption/1-Regular` `font/tertiary` 회색 중앙정렬. CTA 없이 다른 진입점 힌트 (예: "구매 내역에서 취소 가능 여부를 확인할 수 있습니다."). § "하단 유틸리티 링크" 매칭.

### 안티패턴 (하지 말 것 — 상세 화면)

- ❌ 상세 화면 액션바 좌측에 `<` 뒤로가기 — 반드시 우측 `×`만 (모달성)
- ❌ 하단 액션 페어와 고정 CTA 동시 노출 — 상황별 하나만
- ❌ 하단 액션 페어의 넓은 버튼을 brand fill로 — 반드시 아웃라인 (부가 액션 성격)
- ❌ 트랜잭션 리스트에서 "사용"을 검정, "사용 취소"를 회색으로 — 색으로 상태 구분 필수 (§ ⑤ 규칙)
- ❌ 사용 내역 리스트 아이템 사이에 divider — 여백만 유지
- ❌ 상품권 상세에서 잔액 카드 생략 — 상품권은 잔액 표기 필수
- ❌ 아코디언 첫 섹션을 접힘 상태로 시작 — 반드시 "사용 가능 매장"만 기본 확장

## 표준 패턴 — 검색 화면 (SEARCH)

목록 화면 상단 검색 필드에서 진입한 검색 전용 화면. 액션바가 검색 필드로 대체되는 특수 구조.

### 화면 구조

검색 필드 통합 액션바(일반 액션바 대체) → 콘텐츠 3상태 분기: placeholder → 최근 검색어 pill / Active → 실시간 검색 결과 리스트 / 결과 없음 → 빈 상태

### 검색 필드 통합 액션바

일반 액션바 자리에 검색 필드가 통째로. 좌: `<` 뒤로 / 중: placeholder + 돋보기 / Active 우: clear × + 돋보기. Focus 아웃라인 `border/brand` 보라.

- **§ MAIN "상단 고정 검색 필드"와 차이**: MAIN = 액션바 아래 별개 필드(탭 시 검색 화면 진입) / 검색 화면 = 액션바 자체 대체

### 최근 검색어 pill 리스트

placeholder 상태 콘텐츠. 섹션 헤딩 "최근 검색" + 아웃라인 rounded pill(검색어 + 우측 × 개별 삭제) flex-wrap 배치. 긴 검색어는 max-width "..." 말줄임.

- **§ MAIN "서브 카테고리 pill"과 구분**: 서브 카테고리 = 회색 채움 필터 선택형 / 최근 검색어 = 아웃라인 + 개별 × 삭제

### 실시간 검색 결과 리스트

리스트형 상품 카드 (MAIN 2열 그리드와 다름). 각 카드 = 좌 이미지(**96×96**) + 우 정보(상→하: 배지 pill · 브랜드명 · 상품명 · 할인율+가격 — 배지는 info 영역 최상단, 브랜드명보다 위). 카드 사이 divider 없이 여백.
- **그리드와 리스트의 사용 구분**:
  - 그리드 (MAIN 큐레이션 섹션) = 이미지 우선 탐색, 시각 강조
  - 리스트 (검색 결과) = 텍스트 매칭 우선, 정보 밀도

### 검색 결과 리스트 배지 위치 (그리드와 차이)

같은 배지("BEST", "오픈이벤트")라도 리스트 형태에서는 위치가 다름.

| 화면 | 위치 | 스타일 |
|---|---|---|
| **그리드 카드 (MAIN 큐레이션)** | **이미지 좌상단 오버레이** | 이미지 위 pill |
| **리스트 카드 (검색 결과)** | **우측 정보 영역 상단** (브랜드명 위) | 별개 라인 pill |

- 리스트에서는 이미지가 좌측 정사각이라 오버레이가 어려움 → 우측 정보 라인으로 이동
- **배지 색, 위치별로 다름** — MAIN 그리드의 BEST: `color/icon/accent-red` #FF364B / 검색 결과 리스트의 BEST: `color/base/brand-primary` #805AE9. 같은 `label` 컴포넌트(구 label/basic-lable)에서 배경색만 다르게 오버라이드됨.

### 검색 결과 없음 빈 상태

- 중앙 배치: 회색 라인 아이콘 (gift + X 오버레이) + Bold 검정 헤딩 1줄
- **부가 설명 없음** (헤딩 1줄만) — 예: "검색된 상품이 없어요"
- **CTA 없음**
- 검색 필드에 입력값 유지 → 사용자가 검색어 수정으로 재시도

### 빈 상태 3종 통합 구분 규칙

| 유형 | 대표 화면 | 부가 설명 | CTA | 재진입 |
|---|---|---|---|---|
| **커머스 목록** | MAIN 카테고리 미판매 | 짧게 | **유지 (다른 진입점)** | CTA로 |
| **개인 보관** | MY 사용가능 미보유 | **다른 진입점 힌트 포함** | 없음 | 텍스트 힌트로 |
| **검색 결과** | SEARCH 결과 없음 | 생략 (헤딩만) | 없음 | 검색 필드 재입력 |

차이 축: 대안 진입점 유도 방식(CTA vs 텍스트) + 재입력 필드 유무.

### 안티패턴 (하지 말 것 — 검색 화면)

- ❌ 검색 화면에 일반 액션바(중앙 타이틀) 사용 — 반드시 검색 필드 통합 액션바
- ❌ 검색 결과를 2열 그리드로 표시 — 반드시 리스트형 카드
- ❌ 최근 검색어 pill을 채움 스타일로 — 반드시 아웃라인 (§ 서브 카테고리 pill과 구분)
- ❌ 검색 결과 없음에 CTA 추가 — 검색 필드가 재진입 역할, CTA 불필요
- ❌ 검색 결과 없음에 긴 부가 설명 추가 — 헤딩 1줄만
- ❌ 검색어 pill에 개별 × 없이 전체 삭제만 — 개별 삭제 유지 필수

## 표준 패턴 — 브랜드 카탈로그·특정 브랜드 상품 목록

전체 브랜드 리스트 → 특정 브랜드 상품 그리드 진입 플로우.

### 브랜드 카탈로그 화면 (BRANDS)

액션바(`<` + 타이틀) + 진입형 리스트(§ "진입형 리스트" 매칭): 좌 로고 원(40×40) + 브랜드명(bold) + 우 `>` → BRAND_ITEMLIST 진입.

### 특정 브랜드 상품 목록 (BRAND_ITEMLIST)

액션바(`<` + 타이틀 없음, 헤더 배너가 타이틀 역할) + 브랜드 진입 헤더 배너 + 상품 2열 그리드(브랜드명 생략).

### 브랜드 진입 헤더 배너

- 배경: `background/secondary` #F8F9FB
- 로고: 원형 **40×40** (흰 배경 원, `radius-2xlarge`=32=완전 원형)
- 브랜드명: `body/1-Bold` 15px 검정
- 높이: **104px** (header container `con` 기준, padding 16 top/bottom + 로고40+gap8+텍스트24+gap16 구성)
- 역할: 액션바 타이틀 대체 + 브랜드 컨텍스트 시각화

### 브랜드 특정 상품 카드 (브랜드명 생략)

MAIN 큐레이션 그리드와 동일 구조에서 **브랜드명 생략** (헤더 배너로 이미 컨텍스트 명시).

### 브랜드 특정 빈 상태 (헤더 배너 유지)

헤더 배너 유지(컨텍스트 보존) + 중앙 아이콘 + 헤딩 "{브랜드명}에 등록된 상품이 없어요." + CTA 없음. § "빈 상태 3종 통합 구분" 참조.

### 안티패턴 (하지 말 것 — 브랜드 카탈로그·특정 브랜드)

- ❌ BRAND_ITEMLIST 액션바에 브랜드명 타이틀 표기 — 헤더 배너가 그 역할, 중복 방지
- ❌ 브랜드 특정 상품 카드에 브랜드명 병기 — 컨텍스트 중복
- ❌ 브랜드 빈 상태에서 헤더 배너 제거 — 컨텍스트 손실
- ❌ 브랜드 빈 상태에 다른 진입 CTA — 브랜드 특정 화면 성격 유지
- ❌ 브랜드 헤더 배너를 혜택 상세 헤더처럼 그라디언트로 — 반드시 단색 회색

## 표준 패턴 — 프로모션 상세 화면 (SET_LIST)

MAIN 상단 기획 배너 클릭 시 진입하는 프로모션 상세. 프로모션 배너 + 관련 상품 리스트.

### 화면 구조

액션바(`<` + 타이틀 없음) → (조건부) 프로모션 상세 헤더 배너 → 섹션 헤딩(프로모션명, bold 좌측정렬) → 프로모션 상품 리스트(세로 진입 리스트)

### 프로모션 상세 헤더 배너

MAIN "기획 배너"의 확장 상세 형태 — 프로모션 진입 후 전면에 크게 노출.

| 요소 | 스타일 |
|---|---|
| 배경 | 프로모션 성격 컬러 (예: 커피 프로모션 = 연베이지·크림톤) |
| 배지 pill (좌상단) | "기획전" — MAIN 배너와 동일한 커스텀 갈색(`#5F3628`, 전시영역 예외) + 흰 텍스트 |
| 헤딩 (2줄) | `heading/2-bold` 검정 |
| 부가 안내 (1줄) | `body/2-Regular` 회색 |
| 우측 이미지 | 프로모션 상품·일러스트 |

- **§ MAIN "기획 배너"와 차이**:
  - MAIN 기획 배너 = 카드형 (좌우 20 margin, 슬라이드 가능, CTA "자세히보기 >")
  - 프로모션 상세 헤더 배너 = **전면 배너** (화면 폭 100%, 크게, 클릭 진입 후 상세)
- 프로모션 성격에 따라 헤더 배너 생략 가능 (관찰: 프로모션없을때 variant)

### 프로모션 상품 리스트 (진입 리스트)

검색 결과 리스트와 동일 구조에 **우측 `>` chevron 추가** (진입성 명시). 좌 이미지(**96×96**, 검색 결과 리스트와 동일) + 우 배지 pill·브랜드명·상품명·할인율+가격 + 우측 끝 `>`. 클릭 → 상품 상세.

### 상품 카드 3 variant 구분 (그리드 vs 검색 vs 프로모션)

| variant | 배치 | 브랜드명 | 배지 위치·색 | chevron |
|---|---|---|---|---|
| **그리드 카드** (MAIN·BRAND_ITEMLIST) | 2열 그리드 | 포함 (BRAND_ITEMLIST 생략) | 이미지 좌상단 오버레이, BEST=red | 없음 |
| **검색 결과 카드** (SEARCH) | 세로 리스트 | 포함 | 우측 정보 상단, BEST=연보라 | 없음 |
| **프로모션 상품 카드** (SET_LIST) | 세로 리스트 | 포함 | 우측 정보 상단, BEST=연보라 | **있음** |

chevron 유무 = 진입 컨텍스트 표시: 그리드·검색 = 카드 전체 클릭 / 프로모션 = 상품 상세로 별도 진입성 강조.

### 안티패턴 (하지 말 것 — 프로모션 상세 화면)

- ❌ SET_LIST 액션바에 프로모션명 타이틀 표기 — 헤더 배너가 그 역할
- ❌ 프로모션 상품 카드에 chevron 생략 — 진입성 표시 필수
- ❌ 프로모션 헤더 배너를 카드형으로 (MAIN 배너처럼) — 진입 후는 반드시 전면 배너
- ❌ 프로모션 상품 리스트를 2열 그리드로 — 반드시 세로 리스트

## 표준 패턴 — 코나콘 즉시 사용 (QUICK 바텀시트)

결제 시 화면 이동 없이 코나콘을 빠르게 꺼내 쓰는 바텀시트 UI. MY_DETAIL의 상세 화면과 다른 팝업 성격.

### 화면 구조 (바텀시트)

딤 오버레이 + 하단 라운드 카드(대형 바텀시트). 3단 부분 스크롤:
- Fixed 상단: 타이틀 "코나콘 사용하기" (bold 중앙정렬)
- Scroll 중앙: 상품 정보 + 바코드 + 보관함 링크
- Fixed 하단: 상품 선택 pill 탭 + "닫기" CTA

### 바텀시트 안 부분 스크롤 구조

- **Fixed 상단**: 타이틀
- **Scroll 중앙**: 상품 이미지 + 브랜드·상품명·유효기간 + 바코드 + 보관함 링크
- **Fixed 하단**: 상품 선택 pill 탭 + "닫기" CTA

§ 대형 바텀시트 규칙 확장 — 컨텐츠 넘칠 때 부분 스크롤 도입.

### 바텀시트 안 좌우 스와이프 화살표

상품 이미지 좌우 양쪽 (수직 중앙) `<` / `>`. **이전·다음 없을 때 해당 화살표 숨김/비활성**. 하단 pill 탭과 동일 기능(다른 표현).

### 하단 상품 선택 pill 탭

DS 컴포넌트 `tab/sub-ui` (pill = `tab/Sub`). 예시 화면: KeyScreen `10315:6004` (코나콘 사용하기 — 상품권).

- 활성: `color/button/primary` #805AE9 채움 + `body/2-bold` 14/22 흰 텍스트
- 비활성: `color/button/white` 흰 배경 + 1px `color/border/default` #DDD + `body/2-Regular` 14/22 `color/font/tertiary` #666
- pill: 높이 38 (padding 상하 8·좌우 16), radius `radius/button/round` (9999)
- pill 간 gap 4 (`spacing-2xsmall`), 좌측 시작 20
- 가로 스크롤, 우측 끝은 마스크로 fade-out (잘린 pill이 흐리게 보임), 1건일 때 pill 탭 생략
- 탭 영역: 상단 `line/solid` 구분선 → gap 12 → pill 줄 → 하단 padding 16 → "닫기" CTA

**pill 3종 비교**: MAIN 서브 카테고리 = 회색 채움 필터 / MY 세그먼트 = 트랙+흰 활성 카드 고정 라벨 / QUICK = brand 채움 활성 동적 라벨.

### QUICK 상품권 = 잔액+보관함 통합 리스트 아이템

바텀시트 공간 절약. 좌 "잔액"(검정) | 중 금액(`font/brand` Bold) | 우 "보관함 >"(검정 + chevron). 좌·중·우 사이 세로 divider `|`. MY_DETAIL 상세의 별개 잔액 카드 + 진입 링크를 통합.

### QUICK vs MY_DETAIL 상세 비교

같은 아이템 정보를 보여주는 두 화면의 차이:

| 축 | QUICK (바텀시트) | MY_DETAIL (전체 화면) |
|---|---|---|
| 진입점 | 홈 fab · 결제 흐름 중 | MY 리스트 클릭 |
| 형태 | 바텀시트 팝업 (딤) | 전체 화면 모달 (× 닫기) |
| 여러 아이템 | 좌우 스와이프 + 하단 pill 탭 | 없음 (단일 아이템) |
| 부가 정보 | 최소 (보관함 링크만) | 아코디언 4섹션 (사용 가능 매장·제한·주의·고시) |
| 액션 | 하단 "닫기" CTA | 하단 액션 페어 (전달·다운로드) or 고정 CTA |
| 사용 시나리오 | **즉시 사용 (결제 순간)** | 상세 확인·부가 정보 조회 |

### 안티패턴 (하지 말 것 — QUICK 바텀시트)

- ❌ QUICK 바텀시트에 아코디언 부가 정보 섹션 삽입 — 상세 화면 성격이 아님, 최소 정보만
- ❌ 하단 pill 탭을 세그먼트 컨트롤 스타일(흰 활성 카드)로 — 반드시 brand 채움 활성
- ❌ 1건일 때도 pill 탭 노출 — 선택 불필요 시 숨김
- ❌ QUICK 좌우 화살표를 항상 노출 — 이전/다음 없을 때 조건부 숨김
- ❌ 상품권 QUICK에서 잔액을 별도 카드로 — 반드시 보관함 링크와 통합

## 표준 패턴 — 상품 구매 플로우 (ITEM · SELECT_CARD)

  - 브랜드명: 로고 16×16 + gap 4 + `body/2-Regular` 14/22 `color/font/tertiary`
  - 상품명: `body/1-regular` 15/24 `color/font/secondary` #333
  - **할인율 + 원가 취소선**: "10% ~~50,000원~~" (§ `accent/primary` 6용도 ⑥ 매칭) — 할인율 `body/1-Bold` 15 `color/font/accent-red` + gap 4 + 원가 `body/1-regular` 15 `color/font/quaternary` #999 취소선

- 우: 값 "구매일로부터 365일" (`body/1-Bold` 검정)

### 하단 구매 영역 (수량·가격 + CTA)

상품 구매 화면 전용 이중 CTA 영역.

- 상단 `line/solid` 구분선
- 정보 라인 (padding 상하 12·좌우 20): 좌 총 금액 (`heading/2-bold` 20/28 검정) + (조건부) 서브 텍스트 / 우 수량 스테퍼
- 하단 (Fixed CTA): "구매하기" (Large Brand, `button/fixed-bottom`)
- **좌측 서브 텍스트 조건부**: 제한 있을 때만 (예: "최대 5개", "최대 5개 / 인당 8개 제한"). `body/3-Regular` 12/18 `color/font/brand` 보라. 여러 제한은 " / "로 병기.

### ITEM 아코디언 3섹션 (구매 전)

MY_DETAIL 4섹션에서 **"상품 고시 정보" 생략** (구매 전이라 개별 고시 미확정). 나머지 (사용 가능 매장·제한사항·주의사항) + 첫 섹션 기본 확장 규칙은 동일.

### SELECT_CARD (결제 카드 선택 바텀시트)

ITEM에서 "구매하기" CTA 클릭 시 열리는 결제 확정 바텀시트.

- **바텀시트 3단 구조**:
  - Fixed 상단: 헤딩 "코나콘 구매에 사용할 / 코나카드를 선택해주세요" (bold 검정 2줄)
  - Scroll 중앙: 코나카드 리스트 (§ 아래)
  - Fixed 하단: "이 카드로 구매" CTA
- **§ QUICK 바텀시트와 공통** — 바텀시트 안 부분 스크롤 3단 구조 (§ "바텀시트 안 부분 스크롤 구조")

### 결제 카드 리스트 (선택형 카드 리스트)

- **§ "선택형 리스트 카드 (가로 카드 아이템)" 매칭** — 기존 규칙 재사용
- 각 카드:
  - 좌: 카드 이미지 (작은 아이콘, 실물 카드 미니어처)
  - 우 상단: 카드명 (bold 검정, 예: "럭키유카드 퍼플")
  - 우 중단: `{카드 번호}` (회색 caption 플레이스홀더 — § "표기 규칙" 중괄호)
  - 우 하단: 잔액·금액 (bold 검정)
- 선택 상태: **brand 아웃라인 border** (2px `border/brand`)
- 비선택: 회색 아웃라인
- 스크롤 가능

### 바텀시트 부분 스크롤 = 커머스 팝업 공통 규칙 (통합)

QUICK · SELECT_CARD 공통 3단: Fixed 상단(타이틀) + Scroll 중앙(동적 콘텐츠) + Fixed 하단(pill 탭·CTA). § "팝업 / 바텀시트" 확장, 대형 바텀시트 표준 내부 구조.

### 안티패턴 (하지 말 것 — ITEM · SELECT_CARD)

- ❌ ITEM 액션바에 상품명 타이틀 표기 — 상품 이미지·정보 영역이 그 역할
- ❌ 할인율을 판매가와 같은 크기·색으로 — 반드시 red bold, 원가는 회색 취소선
- ❌ 수량 스테퍼 대신 텍스트 입력 필드 — 스테퍼 컴포넌트 사용
- ❌ ITEM 아코디언에 "상품 고시 정보" 섹션 포함 — 구매 후에만 표시
- ❌ SELECT_CARD 바텀시트에서 카드 리스트 스크롤 없음 (모든 카드 fixed) — 부분 스크롤 필수
- ❌ 하단 구매 영역에 서브 텍스트 항상 표시 — 제한 조건 있을 때만
